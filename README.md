# IBM Applied Data Science Capstone - SpaceX Falcon 9 Landing Prediction

**Prepared by:** Shravani Pawar  
**Date:** 18 October 2026

This repository is an independently assembled and reproducible project package aligned to the IBM Data Science Professional Certificate Applied Data Science Capstone. It is not the original Coursera-provided set of graded notebook files. Use your own lab outputs as the source of truth and ensure every cell completes in your environment before final submission.

## Project objective

Investigate historical SpaceX Falcon 9 launches and train classification models to estimate whether a first-stage landing is successful. The work covers API data collection, web scraping, data wrangling, EDA and visualizations, SQL, Folium, Plotly Dash, and predictive modeling.

## Repository layout

- `notebooks/01_API_Data_Collection.ipynb` - GET request, JSON normalization and API inspection.
- `notebooks/02_Web_Scraping.ipynb` - BeautifulSoup title inspection and Wikipedia table extraction.
- `notebooks/03_Data_Wrangling.ipynb` - missing values, types, binary target, cleaned CSV export.
- `notebooks/04_EDA_Data_Visualization.ipynb` - launch site, payload, orbit and success-rate plots.
- `notebooks/05_EDA_with_SQL.ipynb` - SQLite queries over the course dataset.
- `notebooks/06_Folium_Launch_Site_Map.ipynb` - interactive launch-site map export.
- `notebooks/07_Machine_Learning_Prediction.ipynb` - Logistic Regression, SVM, Decision Tree and KNN, cross-validation and metrics.
- `scripts/spacex_dash_app.py` - Plotly Dash launch dashboard.
- `scripts/download_course_data.py` - downloads course datasets into `data/`.
- `IBM_SpaceX_Capstone_Presentation_Shravani_Pawar.pdf` - final presentation PDF.

## Setup

Use Python 3.10 or newer. From the repository root, install dependencies and download the official course datasets:

```bash
python -m pip install -r requirements.txt
python scripts/download_course_data.py
```

Open Jupyter and run the notebooks in numeric order:

```bash
python -m pip install jupyter
jupyter notebook
```

To run the dashboard:

```bash
python scripts/spacex_dash_app.py
```

Then open `http://127.0.0.1:8050`.
